## Question

For the selected native mobile provider and current Android/iOS ecosystems, what
primary-source requirements govern SDK and OS support, macOS and CI toolchains,
reproducible builds, signing/provisioning and key recovery, application IDs,
store tracks and review, privacy manifests and data declarations, permissions,
dependency provenance and SBOMs, accessibility, mobile security standards,
device/network test matrices, performance/startup/crash thresholds, telemetry
and crash privacy, staged rollout, forced/minimum versions, rollback, incident
response, and long-term maintenance?
